# 🃏 Silver — بازی کارتی چندنفره‌ی آنلاین

**Silver** یک بازی کارتی استراتژیک، مبتنی بر حافظه و بلوف است که به‌صورت آنلاین و real-time بین ۲ تا ۴ بازیکن اجرا می‌شود. هدف هر بازیکن این است که در پایان هر دور، کمترین مجموع ارزش کارت‌های داخل «دهکده»‌ی خودش را داشته باشد — بدون اینکه دقیقاً بداند چه کارت‌هایی در دستش قرار دارد!

هر کارت، از صفر تا سیزده، یک نقش و قابلیت ویژه دارد: از دیدن مخفیانه‌ی کارت‌ها گرفته تا دزدیدن، جابه‌جا کردن، محافظت کردن و آشکارسازی کارت‌های رقبا.

---

## ✨ ویژگی‌های کلیدی

- 🔴 **چندنفره‌ی Real-time** با SignalR — بدون رفرش، بدون تأخیر
- 🏠 **سیستم اتاق** — ساخت اتاق، اشتراک‌گذاری کد، پیوستن دوستان
- 🧠 **۱۴ نوع کارت** با قابلیت‌های منحصربه‌فرد (کارت ۰ تا ۱۳)
- 👁️ **دیدن مخفیانه‌ی کارت‌ها** در ابتدای هر دور (پنجره‌ی زمانی محدود)
- 🎭 **بلوف و مدیریت اطلاعات** — فقط تو می‌دونی چی توی دستته (شاید!)
- 🛡️ **محافظت از کارت‌ها** با کارت بادیگارد و کارت افسانه‌ای Amulet
- 🏆 **امتیازدهی خودکار و رتبه‌بندی بازیکنان** بعد از هر دور
- ⏹️ **اعلام دور آخر** توسط هر بازیکن، در هر لحظه از نوبت خودش

---

## 🎮 نحوه‌ی بازی

1. هر بازیکن با ۵ کارت پشت‌ورو شروع می‌کند (داخل «دهکده»‌ی خودش).
2. در ابتدای هر دور، فرصت کوتاهی برای دیدن مخفیانه‌ی چند کارت از دهکده‌ی خودتان دارید.
3. در نوبت خودتان، یا از دسته‌ی اصلی کارت می‌کشید، یا از کارت رو‌شده‌ی بالای دسته‌ی سوخته برمی‌دارید.
4. بسته به نوع کارت کشیده‌شده، می‌توانید آن را با یک یا چند کارت هم‌ارزش از دهکده‌ی خودتان عوض کنید یا مستقیماً بسوزانید.
5. برخی کارت‌ها (۵ تا ۱۲) وقتی کشیده و بلافاصله سوزانده شوند، یک قابلیت ویژه فعال می‌کنند: دیدن کارت رقیب، دزدیدن، جابه‌جایی، آشکارسازی و...
6. دور با یکی از این شرایط پایان می‌یابد:
   - رو شدن دو کارت «اهل دهکده» (Villager) — همان لحظه دور تمام می‌شود.
   - اتمام کامل دسته‌ی اصلی و کارت‌های کمکی.
   - اعلام «دور آخر» توسط یکی از بازیکنان و برگشتن نوبت به او.
7. در پایان دور، مجموع ارزش کارت‌های باقی‌مانده در دست هر بازیکن به‌عنوان امتیاز آن دور ثبت می‌شود (عدد کمتر = نتیجه‌ی بهتر).
8. برنده‌ی هر دور، کارت افسانه‌ای **Amulet** را برای دور بعد دریافت می‌کند — کارتی که مثل بادیگارد یک کارت دیگر را برای همیشه محافظت می‌کند.

## 🃏 راهنمای کارت‌ها

| شماره | نام | قابلیت |
|---|---|---|
| 0 | اهل دهکده (Villager) | اگر دو عدد از این کارت رو شوند، دور فوراً تمام می‌شود |
| 1 | سرباز جوان (Squire) | به ازای هر عدد رو‌شده از این کارت، یک کارت کمکی کنار دسته‌ی اصلی باز می‌شود |
| 3 | بادیگارد (Bodyguard) | اگر رو باشد، می‌تواند از یک کارت دیگر در برابر دیگران محافظت کند |
| 4 | شیطون (Rascal) | به ازای هر عدد رو‌شده، یک کارت بیشتر از دسته می‌کشید و یکی را انتخاب می‌کنید |
| 6 | آشکارساز (Exposer) | یکی از کارت‌های خودتان را رو می‌کند |
| 7 | بیننده (Beholder) | یک یا دو کارت از دهکده‌ی خودتان را مخفیانه می‌بینید |
| 8 | شاگرد غیب‌گو (Apprentice Seer) | یک کارت از دهکده‌ی یکی از رقبا را مخفیانه می‌بینید |
| 9 | غیب‌گو (Seer) | یک کارت از هر دهکده‌ای (حتی خودتان) را مخفیانه می‌بینید |
| 10 | ارباب (Master) | یک کارت دلخواه از دسته‌ی سوخته‌ها برمی‌دارید و با یکی از کارت‌های خودتان عوض می‌کنید |
| 11 | جادوگر (Witch) | کارت بالای دسته را می‌بینید و می‌توانید به هر بازیکنی (حتی خودتان) بدهید |
| 12 | دزد (Robber) | یک کارت خودتان را با یک کارت از دهکده‌ی رقیب جابه‌جا می‌کنید |
| 13 | بدل (Doppelgänger) | مثل هر کارتی که همراهش سوزانده می‌شود عمل می‌کند (وایلدکارت) |
| Amulet | طلسم | کارت افسانه‌ای بدون عدد؛ به برنده‌ی هر دور تعلق می‌گیرد و می‌تواند برای همیشه یک کارت را محافظت کند |

> ⚠️ کارت بادیگارد و کارت Amulet، تحت هیچ شرایطی توسط دزد، جادوگر یا ارباب قابل دزدیدن/برداشتن نیستند.

## 🛠️ تکنولوژی‌ها

**بک‌اند**
- ASP.NET Core (.NET)
- SignalR برای ارتباط real-time
- معماری موتور بازی مجزا (`Silver.Engine`) — کاملاً مستقل از لایه‌ی شبکه

**فرانت‌اند**
- React (Next.js — App Router)
- TypeScript
- Tailwind CSS

---

## 📁 ساختار پروژه

```
silver-game/
├── Silver.Engine/       # منطق خالص بازی (قوانین، امتیازدهی، اکشن‌ها) — بدون وابستگی به وب
├── Silver.Api/          # ASP.NET Core Web API + SignalR Hub
│   ├── Hubs/            # GameHub — نقطه‌ی ورود اکشن‌های real-time
│   ├── Services/        # مدیریت اتاق‌ها و session‌های بازی
│   └── Models/          # مدل‌های اتاق و بازیکن
└── frontend/            # اپلیکیشن React/Next.js
    ├── app/              # صفحات و کامپوننت اصلی بازی
    ├── components/       # کارت، تایمر، مودال تصمیم‌گیری
    └── lib/              # اتصال SignalR و تایپ‌های مشترک
```

## 🚀 اجرای پروژه

### پیش‌نیازها
- .NET SDK (نسخه‌ی سازگار با `Silver.slnx`)
- Node.js (نسخه‌ی LTS)

### راه‌اندازی بک‌اند
```bash
cd Silver.Api
dotnet restore
dotnet run
```

### راه‌اندازی فرانت‌اند
```bash
cd frontend
npm install
npm run dev
```

سپس مرورگر را روی آدرس فرانت‌اند (پیش‌فرض `http://localhost:3000`) باز کنید، یک اتاق بسازید یا به اتاق دوستتان بپیوندید و بازی را شروع کنید.
